# HiveMind — Frontend (Next.js 16 Client & UI)

A modern, responsive, high-performance web interface for the **HiveMind Autonomous Multi-Agent Swarm**. Built with **Next.js 16 (Turbopack)**, **React 19**, and **Tailwind CSS**, this client provides real-time WebSocket progress visualization, interactive agent state exploration, code sandbox preview execution, and workspace integrations for **GitHub** and **Gmail**.

---

## 🌟 What Does the Frontend Do?

1. **Mission Command Center (`/chat`)**:
   - Streams live thoughts, tool calls, and execution steps from multiple sub-agents in real-time over **WebSockets**.
   - **Live Interactive Code & Web Preview**: Automatically extracts pure HTML/JS artifacts generated by the Code Swarm and renders them in an isolated, responsive iframe with Desktop, Tablet, and Mobile viewports + Fullscreen preview.
2. **Interactive Swarm Dashboard (`/`)**:
   - **Live Workspace Integrations**: Displays connection status, feature highlights, and 1-click swarm action triggers for **GitHub** and **Gmail**.
   - **Autonomous Department & Agent Matrix**: Interactive explorer displaying **6 specialized departments**, **24+ agents**, their specific tools, and 1-click mission launch buttons.
   - **Synapse Network Graph**: Visual topology showing inter-department routing pathways.
   - **Synaptic Neural Canvas**: Interactive cursor-reactive particle network (`HiveMindCanvas`).
3. **Document Intelligence Center (`/documents`)**:
   - Drag-and-drop ingestion for PDF, CSV, Excel, Word, and text documents into Qdrant Cloud.
   - 1-click GitHub repository cloning and RAG vector indexing.
   - Real-time indexed document table with chunk counts and deletion.
4. **Bring Your Own Keys (BYOK) & Model Selector**:
   - Allows users to switch seamlessly between **Gemini**, **Groq**, and **OpenAI**, providing their own API keys stored securely in local browser storage.
   - Direct authorization and token management for GitHub and Gmail integrations.

## 🧩 Components & Architecture

### Core Pages (`app/`):
- **`app/page.tsx` (Dashboard)**: The central showcase and entry point featuring the neural canvas, live metrics ticker, integrations cards, and department explorer.
- **`app/chat/page.tsx` (Swarm Console)**: Real-time agent mission execution workspace with conversation sidebar, message streaming, sub-agent step accordions, and iframe sandbox preview.
- **`app/documents/page.tsx` (RAG Knowledge Hub)**: User document management interface supporting local files and GitHub repository vector ingestion.

## ⚙️ Environment Variables

Create a `.env.local` file inside `frontend_next/`:

```env
# ─── Supabase Authentication & Database ────────────────────────
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

# ─── Backend URL (FastAPI Server) ──────────────────────────────
# In local development: http://localhost:8000
# In production: https://your-backend.onrender.com (or Railway URL)
NEXT_PUBLIC_BACKEND_URL=http://localhost:8000
```

> **Note**: `lib/config.ts` automatically converts `http(s)://` to `ws(s)://` for WebSocket endpoints based on `NEXT_PUBLIC_BACKEND_URL`.

## 🏃 Getting Started (Local Development)

```bash
# 1. Navigate to frontend directory
cd frontend_next

# 2. Install dependencies
npm install

# 3. Start development server with Turbopack
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🚢 Production Build & Deployment

```bash
# Verify TypeScript types and generate production build
npm run build

# Start local production server
npm start
```

### Deploying to Vercel:
1. Connect your `frontend_next` GitHub repository on [Vercel](https://vercel.com).
2. Set Framework to **Next.js** and Root Directory to `./`.
3. Add the 3 environment variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and `NEXT_PUBLIC_BACKEND_URL`.
4. Click **Deploy**.
